# Mikey Mitchell's Lesson Plans

A 36-week homeschool curriculum for grades 3–5 in one page: 180 lessons in math, reading and writing, science, history, and geography and civics, with practice labs, weekly spelling, unit tests, term finals, an attendance record and progress reports.

Open it at **https://johnmeq.github.io/mikey-lessons/**. It works offline after the first visit and can be added to the Home Screen.

Progress is saved in the browser on each device. Use Grown-ups → Backup & restore to keep a copy or move it to another device.
